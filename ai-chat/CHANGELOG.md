# 更新日志

## 0.1.2 (2026-07-08)
- 新增 `{prefix}ask test [测试语]` 模型可用性测试命令，通过 TelePilot `ctx.ai.complete` 真实调用当前 Provider 与模型，成功时展示 Provider、模型、耗时和安全返回预览。
- 新增“模型测试语”配置，默认使用普通短句，可按站点限制改成自定义内容，避免固定 `ping`、`health-check` 等测活字样被误拦截。
- 测试命令不写入聊天记忆，返回预览会逐行加安全前缀，避免模型测试结果被裸发成 Telegram/TelePilot 可执行指令。

## 0.1.1 (2026-07-06)
- 新增 AI 输出安全护栏：发送前拦截 `/`、系统指令前缀、纯 `+数字`、已注册 TelePilot 命令和配置的裸文本触发词，避免模型被诱导发送可执行指令。
- 支持从 TelePilot worker 命令上下文中尽力读取内置命令、插件命令、账号命令模板和别名；读取不到时仍按通用命令前缀兜底拦截。
- 新增可配置项：拦截可执行指令输出、安全回复前缀、额外拦截的裸文本；留空安全回复前缀时会尝试识别提示词里的“必须以某前缀开头”要求。

## 0.1.0 (2026-07-06)
- 新增 `AI-Chat` 远程插件（key: `ai-chat`），按 TelePilot 标准插件结构提供 `plugin.json`、`manifest.py`、`plugin.py` 与 `__init__.py`。
- 通过 TelePilot `ctx.ai.complete` 调用已配置的 AI Provider，支持 `{prefix}ask 文本`、回复消息后解释内容、查看 Provider 与清空当前会话记忆。
- 支持私聊直接陪聊、群聊 @当前账号或回复当前账号消息触发，并提供会话白名单、群组限制、短期上下文记忆和输出截断配置。
