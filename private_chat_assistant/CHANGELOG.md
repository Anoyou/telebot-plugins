# 更新日志

## 0.1.2 - 2026-08-15

- 通知模板新增监控账号名，明确提示“您的某某账号收到来自某某的消息”。
- 新增可选的账号级“监控账号名”配置。

## 0.1.1 - 2026-08-15

- 通知改用 Telegram HTML 富文本格式，标题、字段提示和结尾提示加粗。
- 对联系人名称和消息正文进行 HTML 转义，避免特殊字符被误解析。

## 0.1.0 - 2026-08-15

- 新增私聊消息监听，只处理启用账号收到的 incoming 私聊。
- 新增插件专用通知 Bot Token 与通知接收 Chat ID 配置。
- 新增按发送者计算的 60 秒消息汇总窗口，多条消息合并后再通知。
- 新增文本与常见媒体消息摘要，并限制单条与整条通知长度。
- 新增账号隔离的待发送状态持久化、worker 重启恢复和失败重试。
- 排除专用通知 Bot 自身消息，避免接收人选择被监听账号时形成循环通知。
