# 近期发言回复测试 更新日志

## 0.2.3（2026-07-30）

- 显式声明 `payout` 高风险权限并开启资金动作严格 Trace，兼容最新 TelePilot 插件开发指南与运行时权限校验。

## 0.2.2（2026-07-22）

- `name`、`send` 和自定义发放命令统一改用 TelePilot 的 UserBot 专用身份查询，不再依赖 Interaction Bot 是否加入目标群。
- 回复目标消息时直接使用 UserBot 从原消息读取到的姓名；`contact=True` 的联系人姓名不再被主动清空。
- 直接提供用户 ID 时会先用 UserBot 搜索该用户的近期群消息，再解析姓名；匿名管理员仍保持隐藏。
- 最低 TelePilot 版本提升到 `0.71.3`。

## 0.2.1（2026-07-22）

- 修复 UserBot 已保存目标用户为联系人时，把本地联系人备注显示成 TG 姓名的问题；联系人实体中的姓名不再作为公开姓名候选。
- `name` 结果中的 TG 姓名统一展示 TelePilot 公共身份解析器返回的当前公开姓名，并要求 TelePilot 0.71.1 或更高版本。

## 0.2.0（2026-07-21）

- 公开信息结果模板新增 `{tg_name}`、`{tg_username}`、`{tg_id}`、`{is_admin}`、`{tag}` 占位符，默认展示 TG 姓名、带 `@` 的用户名、数字 ID、本群管理员状态和管理员/普通成员小尾巴。
- 继续兼容 `{display_name}`、`{identity_status}`、`{resolved_status}` 等旧模板占位符；历史默认模板会自动使用新版默认内容。
- 匿名管理员和身份未确认状态会隐藏姓名、用户名及数字 ID，自定义模板也无法绕过该保护。

## 0.1.7（2026-07-21）

- 修复 `name` 回复测试把 Telegram username 当成姓名的问题：被回复消息同时包含数字用户 ID、username 与姓名时，现在只使用 `first_name + last_name` 生成清洗后的公开姓名，不再以 username 或数字 ID 冒充姓名。
- 继续要求目标消息的 `from_id` 必须是同一名 `PeerUser`；匿名管理员和频道身份仍不会进入姓名读取路径。

## 0.1.6（2026-07-21）

- 修复回复用户消息执行 `name` 时丢失被回复者公开姓名、错误显示为数字用户 ID 的问题；现在会把被回复消息自身的安全发送者名称交给 TelePilot 身份解析，同时继续拒绝匿名管理员和频道身份的反向识别。

## 0.1.5（2026-07-21）

- 修复一次性 `send` / `name` 命令错误创建群级 UserBot 会话，导致反馈结束后仍持续拦截群消息的问题。
- 两个入口改为 `session_scope=none`，所有完成、参数错误和遗留非命令路径都会返回 `end_session`，反馈结束后立即恢复静默。

## 0.1.4（2026-07-21）

- `name` 姓名解析测试支持直接回复目标用户消息触发，无需手动输入用户 ID；只接受被回复消息自身的真实 `PeerUser`，匿名管理员和频道身份不会被反向识别为真实用户。

## 0.1.3（2026-07-21）

- 新增独立 `name 用户ID` 测试命令，直接回显 TelePilot 解析并清洗后的公开姓名、匿名状态、成员标签和解析状态；不触发 payout，也不搜索近期发言。
- 公开姓名解析结果改为配置页可编辑模板，并提供安全公开姓名、身份状态、标签和解析状态占位符及只读预览。

## 0.1.2（2026-07-20）

- 接入 TelePilot 公共安全身份解析，payout 动作和测试结果会记录清洗后的目标公开姓名，便于验证 Unicode 隐形字符不会进入公开展示。

## 0.1.1

- 按最新 TelePilot MessageOps 契约迁移，近期发言锚点测试统一返回 `payout`，不再声明或调用 `userbot_reply` 通道。
- 更新插件中心说明，明确由平台 userbot 执行锚点搜索和发奖。

## 0.1.0

- 新增账号主人命令测试入口：`send 用户ID 金额`。
- 通过 `payout` / `userbot_reply` 标准动作触发平台搜索目标用户在当前群的近期发言，并回复 `+金额`。
- 补充标准事件订阅、交互入口、能力声明和插件配置说明。
