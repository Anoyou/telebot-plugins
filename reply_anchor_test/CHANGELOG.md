# 近期发言回复测试 更新日志

## 0.1.4（2026-07-21）

- `name` 姓名解析测试支持直接回复目标用户消息触发，无需手动输入用户 ID；只接受被回复消息自身的真实 `PeerUser`，匿名管理员和频道身份不会被反向识别为真实用户。

## 0.1.3（2026-07-21）

- 新增独立 `name 用户ID` 测试命令，直接回显 TelePilot 解析并清洗后的公开姓名、匿名状态、成员标签和解析状态；不触发 payout，也不搜索近期发言。
- 公开姓名解析结果改为配置页可编辑模板，并提供安全公开姓名、身份状态、标签和解析状态占位符及只读预览。

## 0.1.2（2026-07-20）

- 接入 TelePilot 公共安全身份解析，payout 动作和测试结果会记录清洗后的目标公开姓名，便于验证 Unicode 隐形字符不会进入公开展示。

## 0.1.1

- 按最新 TelePilot MessageOps 契约迁移，近期发言锚点测试统一返回 `payout`，不再声明或调用 `userbot_reply` 通道。
- 更新插件中心说明，明确由平台 userbot 执行锚点搜索和发奖。

## 0.1.0

- 新增账号主人命令测试入口：`send 用户ID 金额`。
- 通过 `payout` / `userbot_reply` 标准动作触发平台搜索目标用户在当前群的近期发言，并回复 `+金额`。
- 补充标准事件订阅、交互入口、能力声明和插件配置说明。
