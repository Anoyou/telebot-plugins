# 更新日志

## 0.1.3 - 2026-08-16

- 命令反馈改为原地编辑触发命令消息，默认 30 秒后自动删除，并支持配置开关与延迟。
- 默认只提醒一次；只有明确写入“重复提醒”或“每隔 X 分钟再次提醒”时，才在首次触发后按间隔重复。
- 提醒模板新增 `{count}`、`{reminder_count}`、`{repeat}`、`{repeat_interval}` 和 `{repeat_interval_minutes}` 占位符。
- 任务 ID 改为不带 `#` 的可点击复制格式，`undo ID` 继续兼容带 `#` 输入。

## 0.1.2 - 2026-08-16

- 修复目标用户提醒只显示普通 `@用户名`、不会触发 Telegram 通知的问题。
- 目标用户提醒统一使用基于用户 ID 的 HTML 真实提及，并对用户名、显示名和 Todo 内容做 HTML 转义。
- 取消提醒改为独立的 `undo ID` 指令，并兼容系统命令前缀。

## 0.1.1 - 2026-08-16

- 完成首个可安装测试版本的 TelePilot 远程插件规范校验。
- 修正未回复目标消息时“提醒他/她”可能被识别为提醒自己的问题。
- 补充 UserBot 命令事件、双来源完成确认、标准包导出及过去时间边界处理。
- 保证 Telegram 单次发送失败后仍保留下一轮重复提醒调度。

## 0.1.0 - 2026-08-16

- 新增可自定义触发指令的 Todo 提醒。
- 支持回复用户消息解析目标，并通过 UserBot 回复提醒；直接提醒自己时改用 Interaction Bot @自己。
- 支持中文相对时间、日期时间和自定义时区。
- 支持完成关键词、重复间隔、提醒模板、列表和取消。
- 使用 TelePilot storage 与 scheduler 持久化并恢复未完成提醒。
