# 更新日志

## 0.1.1 - 2026-08-16

- 完成首个可安装测试版本的 TelePilot 远程插件规范校验。
- 修正未回复目标消息时“提醒他/她”可能被识别为提醒自己的问题。
- 补充 UserBot 命令事件、双来源完成确认、标准包导出及过去时间边界处理。
- 保证 Telegram 单次发送失败后仍保留下一轮重复提醒调度。

## 0.1.0 - 2026-08-16

- 新增可自定义触发指令的 Todo 提醒。
- 支持回复用户消息解析目标，并通过 UserBot 回复提醒；直接提醒自己时改用 Interaction Bot @自己。
- 支持中文相对时间、日期时间和自定义时区。
- 支持完成关键词、重复间隔、提醒模板、列表和取消。
- 使用 TelePilot storage 与 scheduler 持久化并恢复未完成提醒。
